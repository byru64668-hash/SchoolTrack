SchoolTrack Redesigned

Modern SchoolTrack inventory app with a vintage-garden pastel icon and interface.

Files include index.html, style.css, app.js, manifest.json, and icons/icon-192.png + icon-512.png.

To update GitHub Pages, replace the existing SchoolTrack files with these files. After the website updates, remove the old Home Screen shortcut and use Chrome's Install and create shortcut again so the new icon appears.

Inventory data is stored locally in the browser/device. Use History > Backup regularly.
